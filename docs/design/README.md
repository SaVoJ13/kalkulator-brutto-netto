# Дизайн калькулятора

Знімки в цій папці зроблені з **HTML-макета** з тими самими токенами та розмірами, що в коді Compose
(шрифт Inter замість Roboto, тож реальні ширини трохи менші). Числа в макеті взяті з реального
`SalaryCalculator`. Справжній вигляд на пристрої дивіться через `@Preview` у `Previews.kt`
(Android Studio → Split/Design).

## Принципи
- **Результат завжди перед очима.** На телефоні підсумок «Netto» закріплений унизу, на планшеті
  результат стоїть у правій колонці (від 840 dp).
- **Один основний вибір на екрані.** Тип договору залитий акцентом, другорядні перемикачі (місячно/погодинно)
  легші: біла «пігулка» на сірій доріжці.
- **Колір ніколи не єдиний носій змісту.** Кожен сегмент смуги розподілу має рядок із назвою й сумою.
- **Мінімум декору.** Картки з 1 dp рамкою без тіней, одна акцентна палітра, світла й темна теми.

## Токени (`AppTheme.kt`)
| Група | Значення |
|---|---|
| Акцент | світла `#2563EB`, темна `#7C9DFF` |
| Підсумок «Netto» | фон `#111A3A` / `#16203A`, сума `#5EE6A8` |
| Розподіл | netto, ZUS, zdrowotna, PIT, PPK: окремі кольори з контрастом ≥ 3:1 до картки в обох темах |
| Попередження | бурштинова плашка з іконкою (не червона: це «результат наближений», а не помилка) |
| Радіуси | 10 / 14 / 20 / 28 dp |
| Типографіка | 12–34 sp, основний текст 15 sp, дрібний не менший за 12 sp |
| Зона дотику | не менша за 48 dp (перемикачі, радіо, сегменти, кнопка теми) |
